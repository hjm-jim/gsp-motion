# 原始 GSP 样式（0.8.0+）

不需要额外样式参数。程序读取已确认的 GSP v5 对象头，自动用于 SVG、PNG、HTML 预览与 MP4；运动时样式继续附着于对应对象。点、线、圆与弧共享同一组字段，分别应用相关属性。

- 白底：继承 GSP 对象原色。名称保持黑色和 CLI 的字号/避让布局，不从点的颜色猜测文字颜色。
- 黑底：采用 CLI 默认线点配色，避免直接使用暗色对象原色；虚实线、线宽与点大小仍继承。
- 线宽四档 0.5 / 1 / 3 / 5 px；点半径四档 1.5 / 2 / 4 / 6 px。点使用背景色细描边，宽度随点档位变化。尺寸固定为输出像素，不随镜头放大。
- 线型为 solid / dashed / dotted；长虚线按笔宽乘以 6/4 分配笔划/间隔，点线使用圆点。抗锯齿与端点可能和原程序略有差异。
- 高亮、角标与填色仍按 effects 生成独立动画叠加层；隐藏对象时叠加效果同步隐藏。

`inspect` 的每个对象带 `nativeStyle`，自动 info.md 带“GSP 原始外观”表。它们是原始输入信息，不能当作黑底最终配色或某帧强调效果。

旧 JSON 若没有 `nativeStyle` 仍可使用，但采用默认外观；要获得原样式，重新解析源 GSP。旧版本、未知布局和非法样式返回 `styleWarnings`，不要据此声称全部样式已复刻。GSP 字体、文字原始位置、透明度和其他未支持构造不在本次样式继承范围。

本版本没有人工覆盖用的 `styles` 请求键或 `--styles` 参数；不要构造这类调用。
