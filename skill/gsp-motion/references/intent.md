# 意图到 CLI：高亮、显示/隐藏、初始显示

先 inspect 并读取 info.md。用当前文件的编号核对目标，区分下面四层状态，再编写需求 JSON。所有例子中的编号都只对指定样例有效。

| 层 | 含义 | CLI 表达 | 不应产生的额外行为 |
|---|---|---|---|
| 原图状态 | GSP 保存的原始显隐 | inspect / info.md 的 originalVisible | 不能把它误当成本讲解段的最终开场要求 |
| 初始显示 | 本讲解段最先向观众展示的图形 | visibility 中 at:0 的 hide/show | 不先展示原图再切换，不自动高亮 |
| 显示/隐藏 | 段内在指定时刻改变可见性 | visibility 中对应 at 的 show/hide | 不加粗、染色、移动点，不连带隐藏依赖 |
| 高亮 | 在当时可见图形上额外强调指定线、点或圆 | effects 的 line / point / circle | 不显示隐藏对象，不隐藏或变淡其他对象，不替换初始画面 |

这里的“显示”是可见性，不是“加亮”。“初始显示”是时间语义，不是另一种强调效果。角标、三角形填色和线段旁的亮色弓形线分别按 effects.md 处理，不混作原对象显隐。

## 将用户原话分解为操作

| 用户原话 | 应做 | 常见误调用 |
|---|---|---|
| “高亮 AB” | 对已可见 AB 添加 line 效果，其余图形保留 | 只 show AB；或隐藏其他线 |
| “高亮点 A / 圆 c” | type:point / type:circle，objects 指向真实对象 | 用 point 参数驱动 A；用 triangle 填色冒充点高亮 |
| “显示辅助线 l” | 在要求时刻 show l | 对 l 加高亮却不改变其隐藏状态 |
| “隐藏圆 c” | hide c，同时原圆名和该圆高亮消失 | 把圆色设成背景色，或删除依赖数据 |
| “开场只显示圆 c 和点 A” | at:0 精确设置可见集合 | 只有 show:[c,A]，导致其他对象仍显示 |
| “先显示圆，再高亮它” | show 事件 + circle 效果，分别对齐指定时刻 | 仅添加高亮，期待隐藏圆自己出现 |
| “取消高亮，圆保留” | 结束 circle 效果，不加 hide | 在效果结束时隐藏圆 |
| “初始保持原图，高亮某边” | 不添加 at:0 显隐，单独 effects | 为“突出重点”擅自删减原图 |

只有“高亮”“显示”“初始显示”仍不足以确定对象、目标集合或时间时，先从上下文和图形信息推断；仍有 实质不同的解释才问用户。尤其“突出/展示/留下/只看”等词不要机械映射为同一个操作。

## 初始画面的精确语义

每个 render 输出使用本地时间轴，从 t=0 开始。分段讲解时，每段的开场按该段 t=0 设置；若将多个讲解段放在同一次输出中，后续段的初始画面应在该段实际起点设置，不能把全部段的开场事件都写到 0。

- 未指定初始调整：继承 GSP 原始显隐。
- “开场隐藏某几条线”：at:0 hide 指定线，其他对象继承原状。
- “开场显示原本隐藏的线”：at:0 show 指定线，其他对象继承原状。
- “开场只显示集合 S”：从 inspect 的全部可控制对象集合 U 生成 `show:S`、`hide:U−S`。不只处理线，还要核对点、圆、弧及其名称；不要遗漏原先可见的其他对象。无效或未支持的对象不能靠 show 变有效，应说明能力限制。
- 时刻 0 的显隐在第一帧计算前生效；无需先导出原图，也不要用 0.001 秒切换来模拟开场，避免闪出不需要的内容。
- 隐藏只控制绘制。隐藏的圆心、构造点等仍参与几何计算；不要删除父依赖或手改 GSP 来实现初始画面。
- 同一对象同一时刻既 show 又 hide 时 CLI 规定 hide 优先；AI 应先消解冲突，不以此规则掩盖互相矛盾的要求。事件对未列出的对象没有影响。

## 高亮遵循当前显隐

检查目标在效果期间的状态：由原图状态、开场事件、已发生的段内事件共同决定，不能只看 originalVisible。

用户描述的“原图隐藏”与 inspect 不符时，先核对输入文件和所指讲解段：可能指本段开场隐藏，而非 GSP 保存状态。不能用示例文件的编号或另一段的事件覆盖当前文件事实；无法从上下文消解时再澄清。

- 原图隐藏但 at:0 已 show 的对象，可以直接高亮。
- 当时隐藏且用户只要求高亮：不要擅自 show，也不要输出看不见的效果后声称成功。说明目标当前隐藏，确认是先显示再高亮，还是保持隐藏。
- 用户明确“显示并高亮”：添加独立的 show 和 effects；不把 show 偷偷提前到开场。
- 高亮期间 hide：原对象及其 line/point/circle 高亮都不画；效果时间表继续走，不自动暂停或重启。再次 show 时仅在原效果仍有效的时间内继续出现。
- 高亮结束只移除叠加层，保留对象当前显隐。临时显示后还要恢复隐藏，必须来自用户的恢复要求，单独写 hide。

line 描线、circle 描圈、point 加粗外圈都保留基础对象、原样式和几何依赖。默认宽度 6px；用户要求“更粗”时结合原始宽度选择更大的 width。点效果用 objects 数组，不用驱动点字段 point。圆高亮只接受 Circle，不把弧当圆。首帧也要高亮时 enter:0；默认入场有动画，start 时刻的叠加层透明，基础对象仍由 visibility 控制。end 时叠加层消失；需要末帧保持强调时先说明现有结束语义，不把 end 当作常驻设置。

角与三角形是独立标记层，可能用隐藏的构造点定位；隐藏某个点并不等于删除角/面标记。用户要它们消失时应结束对应效果，不能假设 point hide 会自动清除所有相关标记。

## 可执行组合示例

使用随工具提供的 demo1_triangle_circumcircle.gsp：圆 #3，点 A #5，边 AB #7；其余编号须先从该文件 inspect 核对。8 秒静态图：开场只保留三角形；2 秒显示圆；3～6 秒同时高亮点、边、圆；5 秒隐藏圆（其圆高亮也随之消失），其余图形不变。

```json
{
  "input":"./demo1_triangle_circumcircle.gsp",
  "output":"./intent-demo.mp4",
  "mode":"static",
  "duration":8,
  "visibility":[
    {"at":0,"show":[2,4,5,6,7,8],"hide":[1,3]},
    {"at":2,"show":[3]},
    {"at":5,"hide":[3]}
  ],
  "effects":[
    {"type":"point","objects":[5],"start":3,"end":6,"width":6},
    {"type":"line","objects":[7],"start":3,"end":6,"width":8},
    {"type":"circle","objects":[3],"start":3,"end":6,"width":8}
  ]
}
```

## 生成前后的核对

生成前整理：本段开场的可见集合；各时刻的显隐变化；各效果的目标、类型、起止；是否确实需要点运动。仅高亮/显隐/开场展示时用 mode:static，不因默认驱动点 A 而新增运动；用户明确要运动才配 point/from/to。没有新造 initialDisplay、highlight、showOnly 请求字段。

导出后检查 t=0、每个显隐事件前后、高亮入场中段和退出时刻、末帧。确认开场无闪现、未被操作的对象仍保留、隐藏目标无残留叠加层、结束高亮没有意外隐藏。退出码 0 和 ok:true 仅说明导出成功，不能代替意图核对。不要用诊断数值或额外说明字放进纯净视频。
