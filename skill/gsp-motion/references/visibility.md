# 隐藏与显示（0.5+）

需求 JSON 中用显式 visibility 列表指定全部目标：

```json
{
  "input":"./diagram.gsp",
  "output":"./clip.mp4",
  "mode":"static",
  "duration":8,
  "visibility":[
    {"at":0,"hide":[7,8]},
    {"at":2,"show":[7]},
    {"at":4,"show":[8]},
    {"at":6,"hide":[7,8]}
  ]
}
```

先 inspect 解析真实编号；示例 7/8 不是通用线名。每个 hide/show 都是对象编号或唯一标签的数组，可同时操作多个点、线、圆等已支持对象。at 默认 0；在该时刻即时切换，持续到该对象的下个事件，末尾保持最后状态。后续时刻覆盖先前状态；相同时刻隐藏优先。未知编号、空事件和拼错字段报错，不自动猜测目标。

只演示显隐时使用 static，不填写驱动点或运动区间；若用户明确同时需要点运动，保留 motion 模式并配合相同 visibility 列表。可通过 `--visibility file.json` 读取单独事件数组，或嵌入需求 JSON。

显式 show 可显示 GSP 原本隐藏的对象，但不能把无效几何变为有效。隐藏线也隐藏其高亮描线；隐藏点也隐藏点标签。没有被列出的依赖对象不会跟着消失。角标和三角形填色是独立 effects，用其时间范围控制，不冒充 GSP 对象编号。

对象隐藏只影响绘制，不删除数据或停止几何重算。结束后不加自动恢复事件；视频末帧和 HTML 停止状态应符合最终列表。默认依旧为纯净视频，仅保留原有点标签。视频按帧取样，极短的可见时间窗可能没有一帧命中；需要时调整时刻/帧率，而不是宣称所有连续时刻都能呈现在有限帧数的视频中。
